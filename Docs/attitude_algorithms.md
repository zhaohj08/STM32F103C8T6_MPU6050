# 姿态解算算法原理与参数整定

本文说明本工程 `Core/Src/attitude.c` 中实现的三种姿态解算算法：互补滤波、Mahony 四元数 AHRS、
一维卡尔曼滤波。内容包括推导思路、代码与公式的对应关系，以及参数整定方法。

---

## 1. 为什么必须做数据融合

MPU6050 提供两类互补的观测：

| 传感器 | 静态特性 | 动态特性 | 能观测的姿态自由度 |
| --- | --- | --- | --- |
| 加速度计 | 静止时能通过重力方向**准确**得到 Roll / Pitch | 运动时额外的线加速度会严重污染结果 | Roll、Pitch（Yaw 不可观测） |
| 陀螺仪 | 短时间积分**准确**、噪声小 | 存在常值零偏与随机游走，积分后角度误差随时间累积（漂移） | Roll、Pitch、Yaw（相对量） |

结论：**用陀螺仪的动态精度 + 加速度计的静态精度**，通过滤波器融合，才能得到长时间稳定、
短时间响应又快的姿态角。这就是"姿态解算"要解决的问题。

## 2. 姿态的数学表示

### 2.1 欧拉角

用三个角（Roll φ / Pitch θ / Yaw ψ）描述机体相对地理坐标系的旋转，物理意义直观，
但存在两个问题：

1. **万向锁**：当 Pitch 接近 ±90° 时，Roll 与 Yaw 的自由度重合，旋转矩阵奇异；
2. 三角函数运算量大，误差累积不线性。

### 2.2 四元数

用四个数 `q = (w, x, y, z)` 表示旋转，满足 `|q| = 1`，即单位四元数。
本工程约定 `q = (q0, q1, q2, q3)` 对应 `(w, x, y, z)`：

- 没有万向锁；
- 四元数微分方程是线性微分方程，数值积分稳定；
- 只需一次归一化即可抑制数值漂移。

### 2.3 四元数 → 欧拉角

`Quaternion_ToEuler()` 中的代码即来自下列公式：

```
roll  = atan2( 2(q0·q1 + q2·q3), 1 − 2(q1² + q2²) )
pitch = asin ( 2(q0·q2 − q3·q1) )          ← 需限幅到 [−1, 1]，否则 asin 域外产生 NaN
yaw   = atan2( 2(q0·q3 + q1·q2), 1 − 2(q2² + q3²) )
```

代码中对 `sin_pitch` 做了 ±1 限幅，这正是为了避免浮点误差让它越界导致输出 NaN。

## 3. 加速度计解算 Roll / Pitch

水平静止时加速度计只测到重力，机体坐标系下重力方向为 `(0, 0, 1g)`。当机体倾斜时：

```
a_measured = Rᵀ · (0, 0, 1)
```

展开可得（`atan2` 用两参数形式，可自动处理全部象限）：

```
roll_acc  = atan2( ay, az )
pitch_acc = atan2( −ax, √(ay² + az²) )
```

本工程为了直观直接输出角度制，等价于：

```c
roll_acc  = atan2f(ay, az) * RAD_TO_DEG;
pitch_acc = atan2f(-ax, sqrtf(ay*ay + az*az)) * RAD_TO_DEG;
```

> 注意：这个公式只在**加速度计测量的就是重力**时成立。物体做加速运动时会产生误差，
> 因此需要判断加速度模长是否接近 1g，并对结果做低通或融合。本工程用 `ACCEL_SQ_EPS`
> 判断模长平方是否过小（接近 0 说明处于自由落体或数据异常），避免除零与错误校正。

## 4. 一阶互补滤波（`ATTITUDE_FILTER_COMPLEMENTARY`）

思路最直观：陀螺积分结果**高通**保留，加速度计解算结果**低通**保留，两者加权相加。

连续域形式：

```
θ(t) = α · [ θ(t−dt) + ω·dt ] + (1 − α) · θ_acc
其中 α = τ / (τ + dt)
```

- `τ` 是时间常数，物理含义是"截止频率"：`fc = 1 / (2πτ)`；
- `τ` 越大 → 越信任陀螺仪（抗加速度干扰强，但零偏导致的漂移收敛更慢）；
- `τ` 越小 → 越信任加速度计（静态更准，但动态时容易抖动）。

本工程 `τ` 默认 0.5 s（对应截止频率约 0.32 Hz），可用
`Attitude_SetComplementaryTau()` 在线修改。

Yaw 没有绝对观测量，只能做纯积分：

```c
att->yaw_deg = Wrap180(att->yaw_deg + gz * dt);
```

`Wrap180()` 把角度归一化到 `(-180°, +180°]`，避免长期运行后数值无限增大。

## 5. Mahony 四元数 AHRS（`ATTITUDE_FILTER_MAHONY`，默认）

Mahony 等人 2008 年提出的非线性互补滤波，是目前嵌入式工程中最常用的六轴姿态解算方案。

### 5.1 核心思想

不直接在欧拉角上做融合，而是：

1. 用当前四元数**推算**重力方向在机体坐标系下的投影 `v̂`；
2. 用加速度计**实测**的重力方向 `â`；
3. 两者的**叉积**即为姿态误差向量（误差轴垂直于二者，模长正比于夹角的正弦）；
4. 用这个误差向量通过 **PI 控制器**去修正陀螺仪的角速度；
5. 用修正后的角速度积分四元数。

### 5.2 公式与代码对应

估计重力方向（由四元数旋转矩阵第三行推导）：

```
v̂x = 2(q1·q3 − q0·q2)
v̂y = 2(q0·q1 + q2·q3)
v̂z = q0² − q1² − q2² + q3²
```

代码中提取了 1/2 因子，因此变量名为 `half_vx / half_vy / half_vz`：

```c
half_vx = q1*q3 - q0*q2;
half_vy = q0*q1 + q2*q3;
half_vz = q0*q0 - 0.5f + q3*q3;      /* 等价于 (q0²−q1²−q2²+q3²)/2 */
```

误差（叉积 `â × v̂`）：

```c
half_ex = ay*half_vz - az*half_vy;
half_ey = az*half_vx - ax*half_vz;
half_ez = ax*half_vy - ay*half_vx;
```

PI 反馈（`two_kp = 2·Kp`，`two_ki = 2·Ki`，乘 2 是为了配合上文的 1/2 因子）：

```c
integral_fb[i] += two_ki * half_e[i] * dt;   /* 积分项：消除常值零偏 */
gx += two_kp * half_ex + integral_fb[0];     /* 比例项：快速收敛       */
```

### 5.3 四元数积分

四元数微分方程 `q̇ = 0.5 · q ⊗ ω`，本工程用**一阶龙格-库塔（RK1）**离散：

```c
gx *= 0.5f * dt;  gy *= 0.5f * dt;  gz *= 0.5f * dt;

q0 += (-qb*gx - qc*gy - q3*gz);
q1 += ( qa*gx + qc*gz - q3*gy);
q2 += ( qa*gy - qb*gz + q3*gx);
q3 += ( qa*gz + qb*gy - qc*gx);
```

最后做归一化 `q ← q / |q|`。**归一化非常关键**：数值积分会引入微小模长误差，
不归一化会让四元数逐渐偏离单位球，进而使姿态缓慢发散。

## 6. 一维卡尔曼滤波（`ATTITUDE_FILTER_KALMAN`）

对 Roll 与 Pitch 各维护一个二维状态量的卡尔曼滤波器，状态向量：

```
x = [ 角度 ; 陀螺零偏 ]ᵀ
```

### 6.1 状态方程与观测方程

```
预测：  x_k = F · x_{k−1} + B · ω_gyro,   F = [1  −dt ; 0  1],  B = [dt ; 0]
观测：  z_k = H · x_k,                    H = [1  0]           （z 为加速度计解算角）
```

过程噪声 `Q = diag(Q_angle, Q_bias)`，观测噪声 `R = R_measure`。

### 6.2 迭代过程（对应 `Kalman1D_Update()`）

```c
/* 1. 状态预测 */
k->angle += dt * (new_rate - k->bias);

/* 2. 协方差预测 */
k->p[0][0] += dt * (dt*k->p[1][1] - k->p[0][1] - k->p[1][0] + k->q_angle);
k->p[0][1] -= dt * k->p[1][1];
k->p[1][0] -= dt * k->p[1][1];
k->p[1][1] += k->q_bias * dt;

/* 3. 计算卡尔曼增益 */
s  = k->p[0][0] + k->r_measure;
k0 = k->p[0][0] / s;      /* 角度增益 */
k1 = k->p[1][0] / s;      /* 零偏增益 */

/* 4. 状态更新 */
y = new_angle - k->angle;
k->angle += k0 * y;
k->bias  += k1 * y;       /* 在线估计陀螺零偏，这是卡尔曼相对互补滤波的最大优势 */

/* 5. 协方差更新（先用临时变量暂存，避免边算边改） */
p00_temp = k->p[0][0];
p01_temp = k->p[0][1];

k->p[0][0] -= k0 * p00_temp;
k->p[0][1] -= k0 * p01_temp;
k->p[1][0] -= k1 * p00_temp;
k->p[1][1] -= k1 * p01_temp;
```

> 协方差更新必须先把 `p[0][0]` / `p[0][1]` 存到临时变量：直接在原位计算时，
> 后一行会读到已被修改的值（经典陷阱），结果会与理论公式不一致。

> 当加速度计观测无效时（模长接近 0），代码只执行状态预测
> `angle += dt * (rate − bias)`，跳过协方差与增益更新，避免把不可信的观测喂给滤波器。

## 7. 参数整定速查

| 算法 | 参数 | 宏 / 接口 | 默认值 | 调大后的效果 | 调小后的效果 |
| --- | --- | --- | --- | --- | --- |
| 互补滤波 | 时间常数 τ | `Attitude_SetComplementaryTau()` | 0.5 s | 更信任陀螺，抗抖动好，但漂移收敛慢 | 更信任加速度计，静态准，动态抖动大 |
| Mahony | 比例增益 Kp | `Attitude_SetMahonyGains(kp, ki)` | 0.5 | 收敛更快，过大时对加速度噪声敏感、易振荡 | 收敛慢，长时间后仍能收敛 |
| Mahony | 积分增益 Ki | 同上 | 0.0 | 能更快消除陀螺零偏，过大时会产生低频振荡 | 零偏靠 `MPU6050_CalibrateGyro()` 硬件侧解决 |
| 卡尔曼 | `Q_angle` | `Attitude_SetKalmanParams()` | 0.001 | 更信任陀螺，跟随快、噪声大 | 更平滑，响应变慢 |
| 卡尔曼 | `Q_bias` | 同上 | 0.003 | 零偏估计收敛更快，过大时估计抖动 | 零偏估计更稳，收敛慢 |
| 卡尔曼 | `R_measure` | 同上 | 0.03 | 更不信任加速度计，抗干扰强 | 更信任加速度计，静态准、动态差 |

**实用整定流程：**

1. 先保证 `MPU6050_CalibrateGyro()` 标定有效（上电时保持静止），这是所有算法的前提；
2. 从默认值开始，静止观察 1 分钟，看输出是否稳定、有无缓慢漂移；
3. 快速摆动传感器，观察跟随是否滞后或过冲：
   - 滞后 → 增大 Kp（或增大 τ）；
   - 过冲/抖动 → 减小 Kp（或减小 τ）；
4. 若静态下仍有缓慢漂移，可给 Mahony 设置一个很小的 Ki（如 0.005）让积分项持续修正零偏。

## 8. 采样率与滤波器带宽的配合

| 参数 | 本工程取值 | 说明 |
| --- | --- | --- |
| DLPF_CFG | 3（44 Hz 加速度 / 42 Hz 陀螺） | 陀螺输出率被降采样到 1 kHz |
| SMPLRT_DIV | 9 | 1 kHz / (1+9) = **100 Hz** 输出率 |
| 实际采样率 | 100 Hz | 由 TIM2 定步长触发 |

采样率应至少是 DLPF 带宽的 2~4 倍。若把 `APP_SAMPLE_FREQ_HZ` 提到 200 Hz，
建议把 DLPF 也放宽到 94 Hz，否则解算出来的姿态会明显"迟钝"。
